# writes every list of them from this table: the levels' Makefile.am,
# man/Makefile.am, the man page's tables, the README's, the report's
# LEVEL and the ReFrame tests' ROUTINES (#199). Edit the table, then run
# src/c/routines.sh (./autogen.sh does); make check fails until the lists
# agree with it.
#
# precision: s single, d double, c single complex, z double complex; the
# directory the routine's source and test are in (single, double,
# complex, complex16), under src/c/level<level>.
# sizes: what -v, -m and -M are, as the man page gives them:
#   v    -v is the vector size
#   mn   -m is M, -M is N
#   mkn  -m is M and K, -M is N
#   nk   -m is N, -M is K
#   n    -m is N (square; no -M)
# family: the operation, whose source, src/c/level<level>/bmb_<family>.c,
